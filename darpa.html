SIGNAL & NOISE · SERIES 3 · DARPA LINEAGE

The agency that built the network
also taught us how to defend it.

Three interactive simulations, one per idea DARPA pushed into the world: how data moves, how you map a network, and how machines now find and fix bugs faster than people. Click inside each one. Break things. Watch what happens.

1969ARPANET's first message, UCLA → SRI. The system crashed after two letters: "LO".
2012Plan X: DARPA program to map and visualize cyberspace like a battlefield.
2016Cyber Grand Challenge: machines hack and patch with no humans. Mayhem (CMU / ForAllSecure) wins.
2025AI Cyber Challenge: AI systems scan 54M lines of code. Team Atlanta wins; tools released open source.
Built by Isaiah C. Anderson · plain JavaScript + canvas, no libraries · Series 1 & 2 gallery · source
Simulations are teaching models, not real tools. Host names and IPs are made up (private / documentation ranges). This project is not affiliated with DARPA.
